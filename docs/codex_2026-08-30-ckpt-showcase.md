# CKPT Showcase — 2026-08-30

Generated by Codex from the local ComfyUI model inventory
(`comfyui-models.md`, 2026-08-29).

## Summary

One NSFW image per NSFW-capable checkpoint on the local M3 Pro MacBook,
run through the local ComfyUI instance (v0.33.4, `http://127.0.0.1:8188`).

- **Scope:** 21 checkpoints — the 14 checkpoints mapped into `nsfw-app`
  plus 7 newly installed NSFW-capable checkpoints (epicrealismXL,
  epicrealism_naturalSin, beautifulRealistic, cyberrealistic,
  illustriousGehenna, animij, ponyRealism).
- **Assembly per checkpoint:** matching detail LoRA (`add-detail-xl` on
  SDXL, `add_detail` on SD1.5), explicit VAE (`vae-ft-mse` on SD1.5,
  checkpoint VAE on SDXL, HyperVAE preserved where present), per-arch
  sampler tuning (turbo/lightning step counts, Pony `score_9` tags).
- **Content guardrails:** every prompt specifies adult women (22–28 yo);
  all negative prompts include underage blockers (`loli, shota, minor,
  underage, teen, …`). No ControlNet was used (pure text-to-image per the
  chosen defaults).
- **Run:** 21 workflows submitted sequentially, all completed successfully
  in ~48 minutes. Fixed seed `20260830` for reproducibility.
- **Framing:** portrait — SDXL 832×1216, SD1.5 640×960, one image each.

## Outputs

All 21 images are in
`outputs/images/ckpt-showcase-2026-08-30/` (via the `outputs/` symlink to
ComfyUI's `output/nsfw` on the SamsungT7 drive), plus a labeled
`contact-sheet.png` preview of the whole batch. Sizes range from ~0.77 MB
to ~1.57 MB; all files were verified (correct dimensions, no blank or
corrupt images). macOS `._*` AppleDouble files inside the folder should be
ignored when reading outputs.

## Workflow assembly details

- **LoRA:** `add-detail-xl.safetensors` on SDXL (strength 0.3–0.4 by style,
  clip 0), `add_detail.safetensors` on SD1.5 (strength 0.4–0.5, clip 0).
- **VAE:** `vae-ft-mse-840000-ema-pruned.safetensors` loaded explicitly on
  SD1.5; SDXL uses the checkpoint VAE (HyperVAE preserved on
  `realistic-v60-hypervae`).
- **Sampler defaults:**

| Arch | Steps | CFG | Sampler / Scheduler | Resolution |
|---|---|---|---|---|
| sdxl | 28 | 6.5 | dpmpp_2m / karras | 832×1216 |
| lightning | 6 | 3.0 | dpmpp_2m / karras | 832×1216 |
| turbo | 6 | 2.0 | euler / normal | 832×1216 |
| sd15 | 25 | 7.0 | dpmpp_2m / karras | 640×960 |

- Pony models use CFG 7.5 and `score_9, score_8_up, score_7_up,
  rating_explicit` prompt tags.
- SaveImage prefix `nsfw/showcase-2026-08-30/ckpt_<slug>` routes outputs
  into the app's `outputs/showcase-2026-08-30/` folder.

## Files & reproducibility

- Generator: `scripts/generate-ckpt-showcase-workflows.js`
  (writes the 21 API-format workflows + `manifest.json` into
  `local-comfyui/workflows/showcase-2026-08-30/`).
- Runner: `scripts/run-ckpt-showcase.js` (submits sequentially, polls
  history, copies PNGs to `outputs/images/ckpt-showcase-2026-08-30/`).
- Contact sheet: `scripts/make-showcase-contact-sheet.py`.
- Re-run the same batch:

```bash
node scripts/generate-ckpt-showcase-workflows.js --seed=20260830
node scripts/run-ckpt-showcase.js
```
