# RunningHub ComfyUI workflow templates

This folder ships minimal **SDXL text-to-image** workflows for NSFW use via
RunningHub's **ComfyUI task API** (bypasses G-2 content safety when you use
your own checkpoint on the platform). Import one of these JSON files in the
RunningHub web UI, save and run it once, then copy the numeric workflow ID
into `.env.local` as `RH_WORKFLOW_ID`.

> These are **RunningHub** templates (referenced by `RH_WORKFLOW_ID`).
> Local ComfyUI workflows generated by `scripts/generate-nsfw-workflows.js`
> live in `local-comfyui/workflows/` instead.

RunningHub does **not** let us create a `workflowId` via API — you must import
the workflow once in the RunningHub web UI, then copy the ID into `.env.local`.

## 1. Import a workflow on RunningHub

1. Log in at [runninghub.cn](https://www.runninghub.cn).
2. Open **工作台 / Workspace** → create or open a workflow.
3. In ComfyUI, use **Load** (or drag-and-drop) and open one of the
   `sdxl-*.json` files from this folder.
4. In the **Load Checkpoint** node, pick a checkpoint that exists on
   RunningHub (the JSON default `juggernautXL_v9.safetensors` is a
   placeholder — choose any **uncensored / NSFW-capable** SDXL model you have
   access to).
5. **Save** the workflow and **run it once** in the UI so RunningHub
   registers it.
6. Copy the numeric **workflow ID** from the browser URL:
   - Example: `https://www.runninghub.cn/workflow/1980237776367083521?source=workspace`
   - `RH_WORKFLOW_ID=1980237776367083521`

## 2. Configure the app

In `.env.local` (next to `RH_API_KEY`):

```env
RH_WORKFLOW_ID=YOUR_NUMERIC_ID_FROM_URL
```

Optional overrides if your exported API JSON uses different node IDs
(defaults match `sdxl-txt2img-api.json`):

```env
RH_WORKFLOW_PROMPT_NODE=6
RH_WORKFLOW_NEGATIVE_NODE=7
RH_WORKFLOW_SIZE_NODE=5
RH_WORKFLOW_SAMPLER_NODE=3
```

Restart the dev server: `npm run dev`.

## 3. Verify

With the server running:

```bash
curl -sS "http://localhost:4000/api/workflow-setup"
```

Expect JSON with `workflowId`, `nodes` (editable fields), and `ok: true`. If
`workflowId` is missing or wrong, you'll get a clear error.

**Troubleshooting RH 810:** `WORKFLOW_NOT_SAVED_OR_NOT_RUNNING` means you
copied the URL ID but did not **save and run** the workflow in the RunningHub
UI. The app returns HTTP **502** with the same guidance on `/api/workflow-setup`
and `/api/generate`.

Then use the UI: **Plan** should show **ComfyUI workflow** instead of G-2
Standard Model routes.

### Import notes

- **Pony Diffusion**: Works best with `score_9, score_8_up, score_7_up` tags
  at the start of the positive prompt.
- **Lightning**: Use lower steps (4–8) and lower CFG (1–3) for best results.

## Node map (default)

| Node | Class | Field we override |
|------|--------|-------------------|
| 6 | CLIPTextEncode | `text` (positive prompt) |
| 7 | CLIPTextEncode | `text` (negative) |
| 5 | EmptyLatentImage | `width`, `height` |
| 3 | KSampler | `steps`, `cfg`, `seed` |

If you change the graph in ComfyUI, re-export **API format** JSON, update the
node IDs in `.env.local`, or adjust the env vars above.
